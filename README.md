Testes de Integração com GenAI
Objetivo
Este projeto demonstra a utilização de Inteligência Artificial Generativa (GenAI) para auxiliar na criação de casos de teste de integração em um cenário de comunicação entre um sistema de vendas e uma API de pagamento.

Cenário
Um sistema de e-commerce envia solicitações para uma API de pagamento a fim de processar transações financeiras durante a finalização da compra.

Prompts Utilizados
Prompt 1 - Geração de cenários de integração
Atue como um analista de testes de software e gere casos de teste de integração para uma API de vendas integrada a uma API de pagamento. Considere cenários de sucesso, falhas de comunicação entre serviços, respostas inválidas e indisponibilidade da API.

Prompt 2 - Geração de casos de erro
Crie casos de teste negativos para a integração entre um sistema de vendas e uma API de pagamento. Inclua dados de entrada inválidos, códigos HTTP esperados e comportamento esperado do sistema.

Conclusão
A utilização da GenAI permitiu gerar rapidamente diversos cenários de integração, aumentando a cobertura dos testes e auxiliando na identificação de possíveis falhas de comunicação entre sistemas.
